# Dev Sea Technology Figma implementation

Responsive vanilla HTML, CSS, and JavaScript implementation of the supplied Figma frame.

Open `index.html` directly, or serve this folder with any static web server.

## Files

- `index.html` — semantic page structure
- `styles.css` — responsive styling and design tokens
- `script.js` — mobile navigation and active-section behavior
- `assets/` — exported Figma imagery and icons
